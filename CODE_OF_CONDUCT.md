# Code of Conduct

DropDroid follows the Contributor Covenant Code of Conduct.

## Our pledge

We pledge to make participation in this project a respectful, harassment-free experience for everyone.

## Expected behavior

- Be kind and constructive.
- Respect different experience levels.
- Focus feedback on the work, not the person.
- Help keep discussions useful and welcoming.

## Unacceptable behavior

Harassment, insults, discrimination, and personal attacks are not welcome in this project.

## Enforcement

Maintainers may remove comments, close issues, or block participants whose behavior harms the project community.
